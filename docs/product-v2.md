# 模型助手 2.0：本地产品版

以原生 macOS 模型管理与独立 Codex 启动为产品范围。支持模型新增、编辑、归档恢复、搜索、供应商模板、Key 更新、模型发现、连接检查、真实调用验证、无密钥导入导出和诊断。保持官方 ChatGPT 登录独立；DeepSeek 直接使用官方 API。没有凭据或未验证的模板不标记可用。

配置库为 versioned JSON，原子写入、乐观并发控制和保存前备份。Key 单独保存在用户私有目录（0700/0600），不通过进程参数、配置导出和诊断日志传递。修改端点后不会沿用旧密钥。每个模型独立实例目录和独立本机网关访问令牌。所有网络操作有超时与响应大小上限；不自动重试计费请求。

网关只监听 loopback，按模型令牌鉴权，不允许请求覆盖上游模型。支持原生 Responses、Chat Completions 和 Anthropic Messages 转换；桥接协议缓冲完整上游响应再发 Responses SSE，保留函数调用与结果往返。第三方专属内置工具不属于通用协议；不能宣称与官方 Codex 功能完全等价。

发布验收：配置/凭据隔离、并发冲突、模型导入、防明文泄漏、三类协议的函数往返、网关访问控制、超时及故障、Swift 编译签名、真实界面增改恢复、实际 DeepSeek 调用。外部供应商无凭据时明确待配置。公共商业分发的公证、跨机器兼容性与供应商实测作为单独发布条件，不能用本机成功替代。
